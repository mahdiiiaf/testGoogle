# Roshd (رشد) - Upwork Clone

این پروژه یک سیستم مشابه آپ‌ورک (Upwork) با سه نوع حساب کاربری است:
1. شرکت (Company)
2. متخصص (Expert)
3. فریلنسر (Freelancer)

## ویژگی‌ها
- مدل کاربر سفارشی با نقش‌های مختلف.
- پروفایل‌های اختصاصی برای هر نقش.
- سیستم ثبت آگهی شغلی توسط شرکت‌ها.
- سیستم ارسال پیشنهاد (Proposal) توسط متخصصان و فریلنسرها.
- رابط کاربری به زبان فارسی و راست‌چین (RTL).
- API کامل با استفاده از Django REST Framework.

## نحوه اجرا

برای اجرای سریع پروژه، می‌توانید از اسکریپت `run_app.py` استفاده کنید.

### پیش‌نیازها
ابتدا کتابخانه‌های مورد نیاز را نصب کنید:
```bash
pip install django djangorestframework django-cors-headers
```

### اجرای پروژه
فقط کافیست دستور زیر را در ترمینال اجرا کنید:
```bash
python run_app.py
```

این اسکریپت کارهای زیر را انجام می‌دهد:
1. ساخت فایل‌های مهاجرت پایگاه داده (Migrations).
2. اجرای مهاجرت‌ها و ساخت دیتابیس `db.sqlite3`.
3. اجرای سرور توسعه بر روی آدرس `http://127.0.0.1:8000/`.

## آدرس‌های مهم
- **صفحه اصلی:** `http://127.0.0.1:8000/`
- **پنل مدیریت:** `http://127.0.0.1:8000/admin/`
- **رابط API:** `http://127.0.0.1:8000/api/`
